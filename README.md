# Unemployment Analysis with Python

## CodeAlpha Data Science Internship – Task 2

### Project Overview
This project analyzes unemployment data in India using Python. It explores unemployment rates across different states and compares rural and urban unemployment.

The project also examines monthly unemployment trends, including changes during the COVID-19 period.

### Dataset Information
Dataset: Unemployment in India

Source: Kaggle – Unemployment in India

- Original records: 768
- Records after cleaning: 740
- Total columns: 7
- Numerical columns: 3
- Categorical columns: 4

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- KaggleHub

### Project Workflow
1. Download the unemployment dataset.
2. Load the dataset using Pandas.
3. Explore the dataset.
4. Check missing values and duplicate records.
5. Clean column names.
6. Remove missing and duplicate records.
7. Perform Exploratory Data Analysis (EDA).
8. Calculate average unemployment rates.
9. Compare unemployment across states.
10. Compare rural and urban unemployment.
11. Analyze monthly unemployment trends.
12. Create data visualizations.

### Visualizations

The project generates four graphs:

1. **state_unemployment.png** – Average unemployment rate by state.
2. **unemployment_distribution.png** – Distribution of unemployment rates.
3. **area_comparison.png** – Rural vs Urban unemployment comparison.
4. **monthly_unemployment_trend.png** – Monthly unemployment trends in India.
